# DARE 敢于未知 · 冒险主题交互网页

一个鼓励冒险精神的电影感交互网页：滑雪视频首屏、头灯照亮溶洞、潜水 / 攀岩 / 滑翔伞 / 跳伞 / 雪山五个视频章节，以及"你的第一步"入门指南。

**在线预览：** https://你的用户名.github.io/仓库名/ （开启 GitHub Pages 后把这里换成你的网址）

## 怎么使用

**方法一：在线看**
点上面的在线预览网址，打开就能看，不需要下载。

**方法二：下载到电脑**
1. 点仓库页面右上方绿色的 **Code** 按钮，选择 **Download ZIP**
2. 解压到任意文件夹
3. 双击 `启动网页.bat`（或直接双击 `index.html`）

> 视频和照片默认从网上加载，需要联网。想离线观看，可以先双击 `下载素材.bat`（Windows 10 1803 及以上），把素材下载到 `assets` 文件夹，之后网页会优先使用本地文件。

推荐用 Chrome 或 Edge 浏览器打开。

## 交互效果

- 开场加载动画，大标题逐行升起、数字滚动计数
- 首屏滑雪视频背景，滚动时画面放大、文字分层推开，大标题跟随鼠标移动
- 头灯揭示区：移动鼠标照亮漆黑的溶洞，按住放大光圈，找到 3 处隐藏的发现点
- 五个冒险章节：视频背景、进场展开动画、逐字母升起的大标题
- 平滑滚动、自定义光标、胶片颗粒、顶部进度条、右侧章节导航、海拔读数
- "你的第一步"：选择一种冒险，查看入门方式、所需时间和安全底线

## 文件结构

```
index.html        页面结构
style.css         样式
js/data.js        所有文字内容和视频、照片地址（改内容只改这里）
js/main.js        动画和交互
js/lenis.min.js   平滑滚动库
assets/           本地视频和照片（运行 下载素材.bat 后才有）
启动网页.bat       双击打开网页
下载素材.bat       下载视频和照片到本地
```
